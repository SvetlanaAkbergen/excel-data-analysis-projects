# Excel Data Analysis Projects

Коллекция аналитических задач, выполненных в Microsoft Excel в рамках финального проекта по аналитике данных.

## Projects

### 1. Territory Sales Analysis
Файл: `Тестирование Аналитик Финальный проект.xlsx`

Анализ продаж по территориям и неделям.

Что выполнено:
- объединение данных из нескольких листов через Power Query;
- расчёт товарооборота на склад;
- недельная аналитика;
- определение TOP-3 территорий по товарообороту;
- определение TOP-3 по товарообороту на склад;
- расчёт долей в общем товарообороте;
- построение сводных таблиц;
- визуализация динамики продаж.

### 2. Excel Final Assignment
Файл: `Задание Финальный проект.xlsx`

Комплексное Excel-задание из трёх частей.

Что выполнено:
- анализ продаж и товарооборота;
- расчёт выручки по продуктам;
- построение диаграмм;
- структурирование неструктурированных данных;
- сегментация пользователей по интернет-трафику;
- сводные таблицы и интерактивные фильтры;
- формирование Test и Control групп для A/B-теста;
- проверка баланса A/B-групп по KPI и регионам.

### 3. Telecom Analytics Test
Файл: `Тестовый кейс Excel Novartis Pharma Services AG .xlsx`

Анализ телефонных звонков и тарифных планов.

Что выполнено:
- расчёт количества звонков;
- анализ начислений;
- расчёт продолжительности разговоров;
- расчёт средней стоимости минуты;
- анализ уникальных абонентов;
- анализ тарифных планов;
- поиск пользователей с максимальными показателями;
- работа с условными вычислениями и массивами.
